# Security Policy

## Supported scope
This educational repository accepts security reports related to repository code, workflows, and dependencies.

## Reporting a vulnerability
Please report vulnerabilities privately through GitHub Security Advisories or by contacting maintainers directly.

Include:
- A clear description of the issue.
- Reproduction steps.
- Potential impact.
- Any suggested remediation.

## Response process
Maintainers will acknowledge reports, triage severity, and publish fixes as soon as practical.
